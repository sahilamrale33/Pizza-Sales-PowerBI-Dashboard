# 🍕 Pizza Sales Dashboard (Power BI)

## Project Overview

This project analyzes pizza sales data using Power BI to uncover business insights such as sales trends, popular pizzas, customer ordering patterns, and category-wise performance.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel/CSV

## Dashboard Features

- Total Sales KPI
- Total Orders
- Total Pizza Orders
- Sales by Category
- Orders by Hour
- Orders by Day
- Sales by Pizza
- Pizza Sold by Name
- Interactive Slicers

## Key Insights

- Total Sales: **817.86K**
- Total Orders: **358**
- Total Pizza Orders: **50K**
- Classic category generated the highest sales.
- Most orders were placed during the morning shift.
- Thai Chicken Pizza and Barbecue Pizza generated the highest revenue.
